Overview

Project Summary

This project demonstrates the deployment of a complete Active Directory Domain Services environment using Windows Server 2022 virtual machines hosted on Hyper-V.

The objective was to simulate a small enterprise network with centralized authentication, DNS, DHCP, Group Policy, file services, and PowerShell automation.

Every configuration was documented, validated, and tested to mirror enterprise deployment procedures and best practices.

Deployment

Active Directory Configuration

1. Install Windows Server 2022

Deploy a new virtual machine, configure a static IP address, rename the server to DC01, and install Windows updates.

2. Install AD DS Role

Install the Active Directory Domain Services role using Server Manager or PowerShell.

3. Promote to Domain Controller

Create a new forest, configure Directory Services Restore Mode, and reboot the server.

4. Verify Domain Health

Confirm DNS registration, replication, SYSVOL, and Active Directory functionality.

Automation

PowerShell Administration

Routine administrative tasks were automated using PowerShell to improve consistency and reduce manual effort. 



Import-Module ActiveDirectory

New-ADUser `
    -Name "John Smith" `
    -GivenName "John" `
    -Surname "Smith" `
    -SamAccountName "jsmith" `
    -UserPrincipalName "jsmith@corp.local" `
    -Enabled $true `
    -AccountPassword (
        ConvertTo-SecureString
        "P@ssw0rd!"
        -AsPlainText
        -Force
    )

Challenges & Lessons Learned

Challenges

  • Configuring DNS correctly before promoting the Domain Controller.
  • Ensuring clients received the correct DHCP options.
  • Troubleshooting Group Policy application using gpresult.
  • Planning an Organizational Unit structure that could scale.

Lessons Learned

  • Active Directory depends heavily on a healthy DNS configuration.
  • PowerShell significantly reduces repetitive administrative tasks.
  • Documenting infrastructure improves troubleshooting and repeatability.
  • Testing every configuration step helps prevent cascading issues.
